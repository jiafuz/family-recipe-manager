# 隐私、内容安全与上线合规

> 本文是产品和工程准备清单，不代替专业法律意见。正式商业上线前应由熟悉中国互联网产品的专业人员复核。

## 1. 主体和备案

- 尽早确定个人主体还是企业主体；计划公开推广、商业化和运营 UGC 时优先企业主体。
- 完成微信小程序注册、认证和类目选择。
- 完成小程序／APP 备案，坚持先备案后服务。
- 使用境内服务器和域名时完成相应备案与域名实名认证。
- 准备可用的客服电话、邮箱、投诉举报渠道和主体联系方式。

工信部备案要求覆盖小程序等分发形态，详见[工业和信息化部关于开展移动互联网应用程序备案工作的通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html%EF%BC%9B)。

## 2. 个人信息清单

上线前建立数据清单，逐项记录：

| 数据           | 用途           | 是否必要 | 保存时间         | 删除方式                 |
| -------------- | -------------- | -------- | ---------------- | ------------------------ |
| 微信身份标识   | 登录和识别账号 | 是       | 账号存续期       | 注销后按规则删除或匿名化 |
| 昵称、头像     | 家庭成员识别   | 否       | 用户主动设置期间 | 用户修改或注销           |
| 厨房和成员关系 | 家庭协作       | 是       | 厨房存续期       | 退出、解散或注销后处理   |
| 菜单与菜谱     | 核心服务       | 是       | 用户保留期间     | 用户删除或厨房解散后处理 |
| 相册照片       | 用餐留影和分享 | 否       | 用户保留期间     | 用户可单张删除           |
| 推荐偏好       | 今日推荐       | 否       | 功能使用期间     | 设置页清除               |
| 行为事件       | 产品改进和安全 | 部分必要 | 短期、按目的设限 | 到期自动删除或匿名化     |

遵循目的明确、最小必要、公开透明和保存期限最短原则，参考[《中华人民共和国个人信息保护法》](https://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)。

## 3. 授权和隐私交互

- 首次进入不一次性索要相册、相机等所有权限。
- 用户点击“拍照”时才申请相机权限。
- 用户点击“从相册选择”时才申请相册权限。
- 拒绝非必要权限后，点菜、菜单和采购清单仍可正常使用。
- 发布公开内容前单独确认公开范围和隐私项。
- 分享预览默认隐藏家庭名称、成员昵称等非必要信息。
- 隐私政策列明使用的第三方 SDK、收集字段、目的和处理方式。

## 4. 用户权利

产品内提供：

- 查看和修改个人资料。
- 退出厨房。
- 删除自己上传的照片和公开帖子。
- 申请导出个人数据。
- 注销账号。
- 撤回非必要授权和推荐偏好。
- 投诉、举报和联系人工客服。

账号注销要处理共同家庭数据：个人身份应删除或匿名化，但其他家庭成员仍需使用的共同菜单可以保留为匿名成员贡献，并在隐私政策中提前说明。

## 5. 儿童和健康信息

- 首版不主动收集身份证、精确位置、病历或疾病信息。
- 过敏、疾病、体重目标等信息可能具有更高敏感性，首版不作为必填项。
- 如未来提供儿童账号或明确面向未成年人，需要增加监护人同意和儿童信息保护机制。
- 营养分析标注为基于家庭菜单的估算，不作医疗诊断或治疗建议。

## 6. 分享广场治理

公开 UGC 功能上线前必须同时具备：

- 文字和图片自动审核。
- 发布前状态：待审核、已通过、已拒绝。
- 用户举报入口和举报分类。
- 运营人员下架、封禁和处理记录。
- 侵权投诉和申诉渠道。
- 频率限制、反垃圾和异常账号识别。
- 公开内容与家庭私密原图隔离。

不能仅依赖自动审核。高风险或被举报内容需要人工复核，运营后台的每次处理都写入审计日志。

## 7. 推荐算法

- 首版使用可解释的规则推荐。
- 用户可以调整推荐主题、来源和数量。
- 明确展示“好久没吃”“近期搭配较少”等推荐理由。
- 不根据非必要敏感信息进行推荐。
- 提供清除推荐偏好和减少个性化影响的入口。

若后续形成面向公众的个性化内容排序和分发，应进一步评估算法推荐相关义务，参考[《互联网信息服务算法推荐管理规定》](https://www.miit.gov.cn/jgsj/waj/wjfb/art/2022/art_a6ae77ea1f5e401eb8cc6819b869fdfa.html)。

## 8. 安全基线

- 全链路 HTTPS。
- 密钥放入云端密钥管理，不进入 Git 和小程序包。
- 数据库、存储和运营后台按最小权限配置。
- 私密文件使用短期签名地址。
- 登录、邀请码、导入链接和上传接口限流。
- 依赖、容器和接口定期进行漏洞扫描。
- 严重安全事件具有通知、止损、调查和复盘流程。
